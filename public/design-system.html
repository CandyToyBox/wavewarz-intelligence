WaveWarZ Design
System

Extracted from the working homepage redesign prototype, July 2026. Every token, component, and pattern here has already shipped in a real browser and been reviewed against Hurricane's Windsurf frontend blueprint and the platform's FRONTEND‑DESIGN‑SYSTEM.md. Nothing on this page is theoretical — it's the system the redesign already runs on.

Color

Deep space navy as the ground, one green for everything that means "go," one blue for everything informational. Red is rationed — sell actions and Artist A identity only. Zero purple, anywhere, ever.

×

No purple, in any shade, anywhere on the platform. The current wavewarz.com uses purple for the "Create Quick BattleZ" button, the battle-explainer modal, the Farcaster share button, and winner overlays. Every one of those is a design-system violation to fix, not a style choice to preserve.

Typography

Three faces, three jobs. Rajdhani is the arena voice — condensed, uppercase, for anything that needs to feel like a scoreboard. Inter carries every sentence a human actually reads. JetBrains Mono is reserved for anything that is data, a label, or a system state — it signals "this number is real."

Usage rules

/* Section kicker — always mono, always tracked out */
.kicker { font-family: var(--mono); letter-spacing: .28em; text-transform: uppercase; }

/* Headlines — Rajdhani, always uppercase, never title-case */
h1, h2, h3 { font-family: var(--disp); font-weight: 700; text-transform: uppercase; }

/* Any onchain number — mono + tabular so digits never jitter */
.stat { font-family: var(--mono); font-variant-numeric: tabular-nums; }

Motion

Three motion primitives cover the whole system. Nothing else animates. All three respect prefers-reduced-motion.

Ping — "this is live"

LIVE
@keyframes ping { 75%,100% { transform: scale(2.6); opacity: 0; } }
/* duration: 1.4–1.6s · used only on the single "live" dot per view */

Equalizer — "music is playing"

@keyframes eq { 0%,100% { height: 14%; } 50% { height: 88%; } }
/* only on the album art of the currently-playing side */

Hover lift & glow — "this is interactive"

/* every clickable surface: transform + shadow, never opacity alone */
transition: transform .35s cubic-bezier(.34,1.56,.64,1), box-shadow .3s;
&:hover { transform: scale(1.05); box-shadow: 0 0 42px rgba(149,254,124,.6); }

Buttons

One primary action per screen, always green, always solid. Everything else is an outline. There is no third button color — that gap is exactly where purple crept in on the live site.

VariantUse forNever
Primary (green)The one action the screen wants: Jump into Battle, Claim, Sign UpMore than one per view
Ghost (blue outline)Secondary paths: alternate CTA, "learn more," navigationAnything destructive or a sell action
Mute (dim outline)The lowest-commitment option — "just watching," dismissA path you actually want people to take

Content Rules

The visual system only works if the words follow the same discipline. These rules came out of the StoryBrand audit of the current site (score: ~4/10) and the redesign copy (score: 9.5/10).

ONCHAIN is one wordNever "on-chain" or "on chain." Always capitalized when it's doing brand work.
No emojisChips and kickers use text and the ping dot only — never an emoji as a bullet or icon.
The customer is the hero"You put SOL behind the one you believe in," never "WaveWarZ lets you trade."
Name the villain, not the feature"Streams pay fractions of a cent" beats "we have better economics."
Numbers are always provableEvery stat links to wavewarz.info or names its source. No unverifiable claims.
Numbered steps mean real sequence01/02/03 only for an actual ordered process — never as decoration.
